    06 项目代码地图（Rephone Security 的 WebRTC 相关代码索引）¶

    状态：🟡 骨架 + 初步索引 ｜ 读者：已在项目里但不知道去哪找代码的人 目的：一张"地图"，从问题到文件一步定位。详细连通逻辑请看 📄 ../监控端WebRTC信令连通逻辑.md。

    6.1 两个代码仓库的关系¶

    仓库 角色 技术栈 一句话职责
    rephone-security 移动端 App（含相机端 + 监控端 + 回放端） Flutter + flutter_webrtc 采集、信令客户端、渲染、UI
    flutter-webrtc-server 信令 + TURN 服务器 Go + gorilla/websocket + pion 转发信令、签 TURN 凭据、维护在线名册、落库在线状态

    6.2 客户端关键文件（rephone-security/lib）¶

    文件 职责 关键符号
    services/signaling.dart 核心信令类：WS 连接、协议收发、Session/PC/DC 管理、状态回调 Signaling、Session、invite/accept/bye、onMessage、_createSession
    services/websocket.dart 简易 WebSocket 封装（自签证书握手） SimpleWebSocket
    services/turn.dart 请求 TURN 临时凭据 getTurnCredential
    config/server_config.dart 服务器 host/port defaultAuthHost defaultAuthPort
    utils/device_info.dart 设备 ID 生成/持久化（camera/monitor 各一份） getOrCreateDeviceId
    pages/camera_endpoint_page.dart 相机端页面：常驻、自动应答 _connectSignaling、Ringing→accept
    pages/monitor_viewer_page.dart 监控端页面：发现相机→呼叫→看画面/对讲 _callCamera、onCallStateChange
    pages/playback_page.dart 回放端：纯 data 会话拉事件/录像 invite(id,'data')、DC 收发

    6.2.1 Signaling 构造参数速查（新手最容易迷路）¶

    Signaling(host, context, {
  userEmail,          // 有值则写进 user_agent（服务器可关联用户）
  useLocalMedia=true, // true=相机会采集；false=监控端只收流
  deviceType,         // 'camera' | 'monitor'；缺省按 useLocalMedia 推导
})
    页面 useLocalMedia deviceType 一句话
    camera_endpoint_page true（默认） camera 出画面的设备，自动接听
    monitor_viewer_page false monitor 看画面的设备，自动呼叫
    playback_page false monitor 拉回放数据的设备，media:'data'

    6.3 服务端关键文件（flutter-webrtc-server）¶

    文件 职责 关键符号
    cmd/server/main.go 装配：MySQL、认证、TURN、WS 路由、HTTP 各 /api signaler.SetDB、wsServer.Bind
    pkg/signaler/signaler.go 信令核心：消息路由、peers 在线表、camera_online 落库 HandleNewWebSocket、NotifyPeersUpdate、authHandler
    pkg/websocket/server.go WebSocket 升级与 HTTP 服务绑定（/ws、/api/turn） Bind
    pkg/turn/ pion TURN 服务器 TurnServer
    configs/config.ini 端口/证书/MySQL DSN/TURN public IP 等 ——

    服务端 HTTP 端点（与 WebRTC 相关部分）¶

    路径 干什么 认证
    /ws WebSocket 信令 无（外部网关/证书层兜底）
    /api/turn 签发 TURN 临时凭据 无
    /api/device/get-bindings 等 设备绑定/相机信息（决定监控端"看哪个相机"） AuthMiddleware

    同一台 TLS 服务（http.ListenAndServeTLS，端口 8086）同时挂载两者：/ws 经 HTTP Upgrade 升级为 WebSocket（即 wss://），/api/turn 保持普通 HTTPS 请求。HTTPS 与 WSS 的区别、两个端点各自的职责，详见 04 章 4.0。

    6.4 一条主链路的代码路径（监控端看相机）¶

    monitor_viewer_page._connectSignaling()
 └─ Signaling.connect()                         signaling.dart
     ├─ DeviceInfo.getOrCreateDeviceId('monitor')
     ├─ getTurnCredential()                     turn.dart
     ├─ SimpleWebSocket('wss://host:8086/ws')   websocket.dart
     └─ onOpen → send new → 等 peers 广播
onPeersUpdate → _callCamera() → invite(id,'video')
 └─ _createSession(建PC/加DC) → _createOffer → send offer
服务端: /ws HandleNewWebSocket → 转发 offer → 相机
相机端: Signaling.onMessage('offer') → Ringing → accept → _createAnswer → send answer
监控端: onMessage('answer') → setRemoteDescription → CallStateConnected
两端: onIceCandidate → candidate 互发 → P2P 建流
监控端: onTrack/onAddRemoteStream → RTCVideoRenderer 出画面

    完整时序图/消息细节：📄 ../监控端WebRTC信令连通逻辑.md

    6.5 关键配置/常量一览（排查先看这里）¶

    常量 值 位置 说明
    defaultAuthHost/Port rephone.top:8086 server_config.dart 信令与 TURN 共用
    keepalive 间隔 15s signaling.dart _keepaliveInterval
    重连间隔 3s signaling.dart _reconnectDelay
    重连上限 999999 signaling.dart 近无限重连
    DataChannel label fileTransfer _createDataChannel 控制消息 + 二进制文件
    TURN TTL 86400s signaler.go 凭据有效期
