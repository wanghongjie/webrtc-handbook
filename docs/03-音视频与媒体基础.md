# 03 音视频与媒体基础

> 状态：⚪ 仅骨架 ｜ 难度：★★☆☆☆
> 本章要解决的问题：**画面到底是怎么从"摄像头"变成"另一台手机屏幕上的一帧"的？**

---

## 为什么需要这一章

前面 01 章已经知道媒体是 P2P 的 RTP 包。但"打包"之前，音视频原始数据经历了 采集 → 编码 → 封包；接收端反向 拆包 → 解码 → 渲染。这一章把中间的每一步讲透，理解后才能回答诸如：
- 为什么分辨率/帧率约束写在 `getUserMedia` 的 mandatory 里？
- 为什么 SDP 里会列出 H.264/VP8 一堆编码？
- 为什么偶发卡顿/马赛克？（丢包、无 FEC/NACK）
- 为什么相机端 CPU 发热？（编码很贵）
